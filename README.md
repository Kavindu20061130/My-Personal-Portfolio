## 🚀 Featured Projects

### 📋 QueueLK - Smart Queue Management System

QueueLK is an intelligent queue management solution developed to reduce long waiting times in Sri Lankan organizations.

✨ Key Features:
- Mobile application for queue reservations
- QR-code based token management
- AI-powered waiting time prediction
- Real-time queue monitoring dashboard
- Cloud-based scalable architecture
- Administrative management system

### ❤️ Help In Hand - Charity Resource Management System

Help In Hand is a web-based platform designed to connect charitable organizations with citizens willing to donate resources.

✨ Key Features:
- Resource request management
- Donation tracking
- Location-based donation collection
- User-friendly web interface
- Improved communication between donors and charities
